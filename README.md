# Exaroton Mod Updater

Two command-line tools for managing mods on an [Exaroton](https://exaroton.com) Minecraft server.

Both scripts are **read-only by default** — destructive actions only happen when the corresponding flag is passed.

## Requirements

- Python **3.10+**
- [`requests`](https://pypi.org/project/requests/)
- [`json5`](https://pypi.org/project/json5/) *(uploader only)*

```bash
pip install requests json5
```

---

## updater.py — Update mods via Modrinth

Checks every mod on the server against [Modrinth](https://modrinth.com) and reports available updates.

**How it works:**
1. Downloads the server's `mods/` directory as a ZIP
2. Hashes every `.jar` and looks it up on Modrinth to identify the installed version
3. Queries Modrinth for the latest compatible version for your loader and MC version
4. Reports what can be updated — with `--update`, prompts **per mod** before applying

```bash
python updater.py --token <TOKEN> --server-id <ID> --game-version 26.2
python updater.py --token <TOKEN> --server-id <ID> --game-version 26.2 --update
```

| Argument | Required | Description |
|---|---|---|
| `--token` | ✅ | Exaroton API token — generate at [exaroton.com/account](https://exaroton.com/account/) |
| `--server-id` | ✅ | Your server's ID (visible in the Exaroton dashboard URL) |
| `--game-version` | ✅ | Target Minecraft version, e.g. `26.2` or `1.21.1` |
| `--loader` | ❌ | Mod loader: `fabric` (default), `forge`, `neoforge`, `quilt` |
| `--update` | ❌ | Apply updates. Without this flag the script only checks |

> Only mods available on Modrinth can be checked. Custom or CurseForge-only mods are skipped automatically.

## uploader.py — Upload local mods to the server

Syncs new mods from a local profile directory to the server. Reads `fabric.mod.json` from each `.jar` to check the mod's target environment — only mods with environment `*` or `server` are uploaded. Mods whose mod ID is already present on the server are skipped.

```bash
python uploader.py --token <TOKEN> --server-id <ID> --path <DIR>
python uploader.py --token <TOKEN> --server-id <ID> --path <DIR> --upload
```

| Argument | Required | Description |
|---|---|---|
| `--token` | ✅ | Exaroton API token |
| `--server-id` | ✅ | Your server's ID |
| `--path` | ✅ | Path to the local mods directory |
| `--upload` | ❌ | Perform uploads. Without this flag the script only checks |
