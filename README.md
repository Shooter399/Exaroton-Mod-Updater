# Exaroton Mod Updater

A command-line tool that checks your Exaroton Minecraft server's mods against [Modrinth](https://modrinth.com) and optionally updates them.

## How it works

1. Downloads the server's `mods/` directory as a ZIP via the Exaroton API
2. Hashes every `.jar` and looks it up on Modrinth to find the installed version
3. Queries Modrinth for the latest compatible version for your loader and MC version
4. Reports what can be updated — and with `--update`, prompts you per mod before applying any changes

Running without `--update` is fully **read-only**.

## Usage

```bash
python updater.py --token <TOKEN> --server-id <SERVER_ID> --game-version <MC_VERSION> --loader <LOADER_NAME>
```

Add `--update` to actually apply updates:

```bash
python updater.py --token <TOKEN> --server-id <SERVER_ID> --game-version <MC_VERSION> --loader <LOADER_NAME> --update
```

### Arguments

| Argument | Required | Description |
|---|---|---|
| `--token` | ✅ | Exaroton API token — generate at [exaroton.com/account](https://exaroton.com/account/) |
| `--server-id` | ✅ | Your server's ID (visible in the Exaroton dashboard URL) |
| `--game-version` | ✅ | Target Minecraft version, e.g. `26.2` or `1.21.1` |
| `--loader` | ❌ | Mod loader: `fabric` (default), `forge`, `neoforge`, `quilt` |
| `--update` | ❌ | Apply updates. Without this flag the script only checks |

## Requirements

- Python **3.10+**
- [`requests`](https://pypi.org/project/requests/)

```bash
pip install requests
```


> **Note:** Only mods available on Modrinth can be checked. Custom or CurseForge-only mods are skipped automatically.
